# Laboratorio Full Stack HTTP

Proyecto académico de Ingeniería Informática para practicar la comunicación entre un frontend React y un backend Node.js mediante HTTP.

## Tecnologías

- Node.js
- React
- Vite
- JavaScript
- HTTP
- CORS
- Git y GitHub
- PM2
- Nginx
